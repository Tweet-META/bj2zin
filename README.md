# 学生校园信息站原型

这是一个不代表学校官方立场的学生向静态网站原型。

## 目录

```text
.
├─ index.html
├─ assets/
│  └─ css/base.css
├─ School/
│  ├─ index.html
│  ├─ Courses/index.html
│  ├─ Clubs/index.html
│  └─ Info/index.html
├─ OffCampus/
│  ├─ index.html
│  ├─ TOEFL/index.html
│  ├─ SAT/index.html
│  └─ AP/index.html
├─ Planning/index.html
├─ Community/
│  ├─ index.html
│  └─ Experience/index.html
└─ Tools/index.html
```

直接打开根目录下的 `index.html` 即可浏览。四个主板块使用独立文件夹；经验归入交流，工具保留独立目录并仅作为导航入口。后续内容可继续按相同方式增加子目录。
